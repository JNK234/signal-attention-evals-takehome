# Evaluating Cartogram's attention agent against its specification

Narasimha Jwalapuram. Signal Labs AI-engineer take-home, September 2026.

## Setup

Signal Labs builds the layer that decides which few things, out of everything an organisation produces, a human should look at today. At Cartogram, the fictional customer in this assignment, that layer is an account-risk attention agent. It watches 180 customer accounts through product telemetry (daily usage metrics such as active seats and API calls) and through text artefacts: support tickets, email threads, chat, CRM notes, meeting notes, surveys, security reviews, billing events and monitoring alerts. When one of eight detectors fires, for example a usage cliff or a billing dispute, the agent opens a signal. It gathers evidence, forms a hypothesis about the cause, assigns a severity and a confidence, and decides whether to route the signal to the account's owner, a customer success manager (CSM), or to suppress it. A dossier is the agent's complete record of one signal: every state it moved through, every artefact it attached with a quoted excerpt, every numeric claim it made, every action and notification, and its final decision.

The assignment supplied a specification that defines how the agent must behave. It is written as a state machine over the life of a signal, with invariants, timing targets, policy and containment rules, materiality rules, grounding rules for numeric claims, and quality expectations. The assignment also supplied 629 dossiers from a 21-week period, the telemetry (32,032 account-day rows), 3,810 artefacts, the account and owner records, renewal outcomes observed afterwards, and quality labels from three annotators who each labelled 240 dossiers. The task was to build an evaluator that takes one dossier and returns four things: a quality score, a risk score, a verdict on whether the signal deserved human attention, and the list of specification rules the dossier broke. On top of that evaluator, the assignment asked for a violation report, an attention-budget analysis, and this writeup.

The difficulty is that a dossier cannot be judged from its own contents. The agent quotes percentage changes computed on telemetry that carries pipeline distortions. It quotes evidence that may not exist or may belong to another account. It reports its own ARR-at-risk figure. The outcomes name the signal as the cause of the renewal result in only 28 of 629 cases, and the fields that record a complaint or a wasted escalation exist only for signals a human saw. The three annotators disagreed on 31% of the dossiers they all labelled. Every claim in a dossier therefore has to be checked against the source it cites, and every number this writeup reports has to say which population it was measured on.

## Methodology

**The evaluator is a source-anchored audit: it recomputes what the agent claimed from the data the agent cited.** Figure 1 shows the path one dossier takes. Two things are built once: a table of rules transcribed from the specification, and a truth layer built from the data files. Each dossier then passes through eleven checks that emit violations, and three scores are computed from those violations and from a small set of facts the checks record. This section walks that path in order. It then explains how the three scoring formulas were reached, because each one came out of several rounds of measurement rather than a first guess.

![Figure 1. The path one dossier takes through the evaluator.](figures/pipeline.png)

**From the specification to 29 rules, by hand.** I read the specification once and transcribed it into a table of 29 rules. Each rule carries the identifier the specification uses, for example I6 for evidence integrity, M6 for grounding numeric claims, or §8.2 for the legal-hold containment rule. It also carries the section it comes from, a severity class, and the check that owns it. The severity classes come from the specification's own summary table in §11. That table calls invariant violations, fabricated evidence, containment failures and missed mandatory routes critical; invalid transitions and materiality or grounding errors high; timing failures medium to high; and quality failures variable. I mapped those words onto four classes with weights of 1.0 for critical, 0.6 for high, 0.3 for medium and 0.1 for soft. The code documents two departures from the table. §8.6 (wrong notification channel) is soft because the specification itself calls it low-severity. Timing is split: the time-to-attention target and the re-notification limit are high, the notification window and the staleness rule are medium. Nothing parses the PDF at run time; a hand-written table is easier to audit than a parser. Seven tests parse the section numbering of the LaTeX source instead. They fail if any rule cites a section that does not exist, if any emitted identifier is one the specification does not name, or if any coined name lacks an entry in a definitions file.

**The truth layer corrects the telemetry and indexes everything else.** The evaluator's optional `load_context` call receives the accounts, owners, telemetry, artefacts and the other dossiers. It indexes the records by identifier and corrects the telemetry in five ordered steps. First, where an account-day appears twice, the row with the later ingestion timestamp wins, because the later row is a backfill. Second, for accounts on the legacy collector, it halves API calls before 18 May 2026, because the collector double-counted until that date. Third, it multiplies the p95 latency before 27 April by 1.8, because the instrumentation changed on that date. Fourth, it marks as unusable any row where seats, API calls and data volume are all zero while the status still reads ok, and any row flagged degraded. Fifth, missing days stay missing. This last rule matters most. A naive reader fills a missing day with zero and sees a collapse; the evaluator refuses to compute a number over a window it cannot see. To recompute a percentage change, it pairs each day in the claimed window with the same weekday one window earlier and sums only the pairs where both days are usable. Weekends, missing days and the apac time-zone shift then cancel. The truth layer also builds a cohort baseline for each account: the median change of its industry or region peers over the same days, leaving the account itself out. A drop the whole cohort shares then reads as a calendar or pipeline event.

**A small local model reads the text, and structure gates every verdict it gives.** Artefacts are messy. Quoted email history repeats old complaints under a new positive message, signatures carry contact details, and sarcasm defuses complaints. The evaluator first splits each artefact at quote-depth boundaries. Text under a "wrote:" line, below a forwarded-message divider, or prefixed with ">" is tagged as quoted history and can never fire a trigger. This splitter is a set of regular expressions over the conventions the corpus uses. A convention it does not list would read as current text, and the Limitations section states that. Trailing signatures are tagged the same way. A zero-shot natural-language-inference (NLI) model then scores the current blocks. An NLI model takes a passage and a written sentence and returns how strongly the passage entails the sentence; zero-shot means it was never trained on this corpus. I chose the model, DeBERTa-v3-base fine-tuned for zero-shot classification (184 million parameters, runs offline), from a bake-off of three candidates on hand-written fixtures. It separated 11 of 12 labels with clearly bimodal scores and read German, Spanish, Portuguese and Japanese cancellation notices correctly. A multilingual NLI model scored almost everything near 1.0 and separated only 7 of 12. The model scores twelve labels: the five mandatory-route triggers from §8.1 (cancellation intent, legal reference, security incident, champion departure, billing dispute), sarcasm, and six hypothesis topics from §3.2. Each label has several written sentences and takes the highest score, so recall does not hinge on one phrasing. A score becomes True above an upper threshold, False below a lower one, and abstain in between. I calibrated the thresholds on one half of 176 fixtures and checked them on the other half, where the model got 64 of 68 right with 2 abstentions. Four structural gates sit in front of every model verdict. The artefact must exist and belong to the account. The quote must appear verbatim. The block must be current. A cancellation or security trigger must come from a customer author. The 43,679 scores for this corpus are committed as a cache, so the grader's machine reproduces every result with no model download. The model sits behind a four-line interface, so any scorer can replace it. With neither model nor cache, the evaluator marks the four text-dependent rules as unevaluated and still returns everything else.

**Each dossier passes through eleven checks in a fixed order, and every violation carries its explanation.** The evaluator first coerces the dossier into the expected shape and records what it changed. A malformed field can therefore never hide findings on valid fields, and nothing in `evaluate()` raises. The checks then run in this order: lifecycle, actions, hypothesis count, timing, materiality, evidence, policy, grounding, duplicates, mandatory route, and hypothesis quality. The lifecycle check is a finite-state acceptor over the recorded transitions and covers I1 to I3 and the transition matrix. The actions check tests each action against its allowed transition (§5). Timing runs in the owner's local time zone (§6.1 to §6.4 and §8.6). Materiality is integer arithmetic (M1 to M5). Evidence integrity tests existence, account and verbatim match (I6 and §8.4). Policy covers containment (§8.2, §8.3, §8.5, §8.7). Grounding recomputes each numeric claim on the corrected telemetry (M6). Duplicates looks across the other dossiers (Q5). The mandatory-route check applies §8.1, and the quality check applies Q1 to Q4. Eight of the eleven are pure logic. Three consume model verdicts: evidence staleness, the mandatory route, and the hypothesis-fit rule Q2. Each violation is a record of the lifecycle step, the rule identifier, a severity and a one-line explanation. The explanation names the offending identifiers and numbers, for example "api_calls claimed −61% reproduces only on uncorrected data (raw −58.2%; paired +1.3% on 7 of 7 pairs), manufactured decline". Severity is the class weight, halved when the finding is uncertain, for instance a trigger the model abstained on or a departure the evaluator could not attribute to a named person. Magnitude never changes severity; it lives in the explanation. A second entry point, `explain()`, returns the same result plus 31 recorded facts: which triggers fired and from which artefact, whether a human was reached, the status of each numeric claim, the cohort match, and so on. Every analysis script in this repository reads those facts instead of re-deriving them.

**The quality score is a product of per-rule penalties whose slope comes from the annotators.** The formula is

    quality = Π over broken rules of (1 − 0.16 · w · c)

where w is the class weight (1.0, 0.6, 0.3 or 0.1) and c is 1 for a confirmed finding and 0.5 for an uncertain one, with one penalty per rule. Five forms preceded it. The first used weights chosen by feel. The second zeroed the score on any critical violation. I rejected it because no annotator ever scored a dossier at zero (their minima were 0.30, 0.27 and 0.88), and because it collapses two axes the specification keeps apart: quality is how well the dossier was built, risk is how much harm it can cause. The third added a floor of 0.25 with no source. The fourth summed the penalties and clipped at zero. The annotators' own behaviour suggested that form: regressing each annotator's quality score on the severities they recorded gives a straight line, with slopes of −0.161, −0.162 and −0.145 and R² of 0.60, 0.82 and 0.70. But the clipped sum pinned 134 of 629 dossiers (21%) at exactly 0.0, two of them with no critical violation at all. Terwee and colleagues' 2007 criteria for measurement instruments call more than 15% of scores at the lowest value a floor effect: those dossiers cannot be told apart. The product form removes the floor (one dossier remains at it) and keeps the rank order; the Spearman correlation with each annotator moved by less than 0.015. It is also the same algebra the Common Vulnerability Scoring System (CVSS) uses for its impact sub-score. Last, I re-anchored the penalty magnitude. An earlier table charged 0.50 per critical finding, three times the annotators' slope, and sat every score 0.29 below every annotator. Setting the slope to 0.16 and keeping the specification's 10:6:3:1 class ratios moved the evaluator's median quality from 0.54 to 0.80, against annotator medians of 0.80, 0.83 and 0.96. The three annotators agree on the cost of a finding to within 0.017 and disagree on their baseline by 0.15, which is why only the slope is borrowed.

**The deserved-attention verdict is a table of specification obligations, reached after two versions that measured worse.** The specification never says positively what deserves attention; it states two obligations. §8.1 lists five triggers that must reach a human, and §4.6 says a signal whose enrichment timed out must still reach a human. The first version of the verdict had eight conditions, only one of them from the specification, and fired on 215 dossiers, including a 25-day-old feature request. The second kept only the two obligations and fired on 106. Measured against the three annotators, that version had a Cohen's kappa of 0.04, 0.10 and 0.02, all with confidence intervals crossing zero. Kappa is agreement beyond what chance predicts from each rater's yes-rate, so those values mean no agreement at all. Trivial baselines beat it: calling every P0 or P1 signal deserving scored an F1 of 0.57 against the annotators' majority vote, and the spec-only version scored 0.19. Before testing any candidate, I split the 130 dossiers all three annotators labelled into 71 development and 59 held-out dossiers by hashing the signal identifier. No candidate could then be tuned on the held-out half. That split earned its keep when one candidate scored 0.39 on development and 0.09 on held-out. I then swept 106 candidate policies built from 14 atomic predicates. Each was tested against the majority vote with a permutation test, which shuffles the labels 3,000 times to see how often chance alone reaches the same score. Every survivor had to keep all 18 verdicts I had derived by hand from the specification before running the evaluator. Every evidence-only predicate was noise (p between 0.15 and 0.42). The only real signal was the agent's own severity, and §6.3 gives that severity meaning: P0 means act today, P1 means material risk with corroboration. So I added a third row: the agent assigned P0 or P1 with a non-benign hypothesis, and a departure claim must sit inside the 90-day renewal window. That row raised the F1 against the majority from 0.19 to 0.38 (permutation p = 0.026), kept 18 of 18 hand-derived verdicts, and brought the count to 163. The code marks the row as an inference and a test asserts the marking. One predictor I refused on principle. The agent's own ARR-at-risk figure was the strongest single signal on held-out data, but it is wrong on 59 dossiers, and an evaluator must never let a self-reported number veto a route the specification requires.

**The risk score is a noisy-OR over ten harm conditions with unfitted magnitudes.** A noisy-OR combines independent causes of one outcome. If condition i causes harm with probability p_i, the probability that at least one does is

    risk = 1 − Π over fired conditions of (1 − p_i · c_i)

with c_i the same certainty factor as above. The ten conditions are the six containment and integrity rules (§8.2, §8.3, §8.4, §8.7, I6, §8.1), the two materiality rules M4 and M6, and two judgments read from the domain guide: a customer-visible play on an undeserving signal, and a deserving signal that never reached a human. Their probabilities are 0.45 for critical, 0.20 for high and 0.15 for the two judgments. The first version had seven additive coefficients that cited nothing. I rejected fitting coefficients to outcomes because 16 complaint events cannot support a weight per condition, and an evaluator that will run on dossiers nobody has seen should not encode one sample's accidents. I rejected summing because 15 of the 16 complaints fire two conditions at once, so a sum charges one event twice. The 0.45-to-0.20 step borrows the ratio between CVSS's high and low impact levels (2.55×). The judgment tier sits below the high tier on the GRADE principle that inferred evidence never outranks rated evidence. A weight-share audit then showed that the wasted-CSM-slot harm held 12% of the score's mass while the annotators raised it in 53% of their flags. I swept four materiality candidates on a second pre-registered split and added M4 (routing a signal below the materiality floor), the only one with an effect. Two conditions that describe one event, a suppressed mandatory trigger and a deserving signal that reached no human, are grouped and charged once.

**Validation uses three ground truths, and every number below says which one it rests on.** The annotators' majority vote is the reference for agreement statistics. Twenty-seven golden dossiers are the reference for correctness; I derived their expected violations and verdicts by hand from the specification and the raw records before running the evaluator on them. The renewal outcomes are the reference for harm, with the caveat from Setup. Two pre-registered development/held-out splits guard the deserved and risk definitions. "Not fitted to this corpus" covers the magnitudes. Which conditions exist in the risk score was chosen partly by held-out performance, and that is model selection; the Limitations section records it. Seven hundred and fifty-one tests cover the checks, the scores, the cold path and the provenance of every constant.

## The data

**The telemetry carries six distortions, and three of them are not in the documentation.** The file holds 32,032 rows for 31,698 distinct account-days over 181 days. 334 account-days appear twice, 882 are absent, 72 rows are flagged degraded, and 48 rows across 7 accounts show zero seats, zero API calls and zero data volume while their status still reads ok. The domain guide documents three events: the legacy collector double-counted API calls until 18 May 2026, the p95 latency metric changed scale by about 1.8× on 27 April, and the apac and emea rows for 11 to 13 June never arrived. Three more surfaced only from inspection. The duplicate rows are backfills whose later version is the correction. The zero rows marked ok are collector outages, so an account that looks dead is one whose meter stopped. And apac daily active users are bucketed by UTC day, which shifts that region's weekly curve by one day. Each of these makes a healthy account look as if it collapsed, on the same date, across a whole cohort.

**The correction rule was refuse, never zero, and it changed what the corpus says.** Methodology gives the five steps. The effect is that 259 of the 629 dossiers state a percentage change that does not reproduce on corrected telemetry, and 197 of those reproduce on the raw file. The 259 split three ways by what the corrected data shows: in 121 a real decline existed and the agent overstated it, in 80 the claim matches neither series, and in 58 the pipeline manufactured the decline outright. Those three groups behave differently later, which is the M6 finding in Findings.

**The load is bursty because detectors sweep whole cohorts on Sundays, and each burst has a named cause.** Signals per week have a median of 21 and a maximum of 107, and 427 of 629 signals opened on a Sunday. Six weeks hold 40 or more signals and together 58% of the corpus (Figure 2). Two are pipeline events. Week 21 is the 18 May collector migration: 37 of its 43 artefact-status claims cite the legacy metric. Week 24 is the June ingest gap: 64 of its 72 cite the missing days, and 86 of its 107 accounts sit in apac or emea. Four are public holidays: Good Friday, the 1 May Labour Day, Memorial Day and 3 July. On Memorial Day the median North American account fell from 35.1 active users the week before to 7.8, while its error rate held at 0.44 to 0.46, and on each holiday week 5 to 10 affected accounts had an out-of-office or holiday artefact within 14 days. A first draft claimed the drop persisted into July; the same-weekday medians for the following six weeks sit inside the pre-holiday range, so that claim was withdrawn. `attention_budget.md` section 1 carries the full table.

![Figure 2. Signals per week with the cause of each burst week.](figures/signals_per_week.png)

**The detectors are low-recall, which contradicts §3 of the specification.** I re-ran the two threshold detectors on corrected telemetry. usage_cliff (a week-over-week API-call drop above 34%) fired for 92 of 322 real episodes, a coverage of 29%, and 84 of its 205 dossiers match a real episode, a precision of 41%. seat_decay (a seat drop above 29%) reached coverage 23% and precision 51%. On raw telemetry the same thresholds would have seen 517 and 596 episodes, so roughly 195 and 140 of the episodes the detectors reacted to were manufactured by the pipeline. The text side is worse: exec_churn_language carries no current trigger in 125 of its 143 dossiers, and 48 written mandatory-route triggers (23 departures, 14 billing disputes, 5 cancellations, 5 legal references, 1 security incident) have no dossier within 14 days. The specification calls the detectors "deliberately high-recall". The corrected data shows 23% to 29%.

**Two text traps mattered for the results.** Quoted email history is the first: three dossiers fire an executive-churn reading only on text under an "On 02 Mar 2026 … wrote:" line, and the quote-depth splitter is what stops that. Appended contact details are the second: 17 dossiers quote an artefact with an email address appended that is absent from the artefact in 16 of them, which is both a fabricated quote (I6) and a contact-detail leak (§8.7).

## Annotator disagreement

**Four statistics appear in this section, so here is what each measures.** Cohen's kappa is agreement between two raters after subtracting the agreement chance alone would produce from their yes-rates; 0 is chance, 1 is perfect. When both raters say "no" about 80% of the time, as here, kappa drops even when they agree often. So I report PABAK beside it: prevalence-adjusted bias-adjusted kappa, which is two times the raw agreement minus one and ignores the base rate. Spearman's rho is the correlation between two raters' rankings of the dossiers, so it measures order and ignores level. Krippendorff's alpha is chance-corrected agreement for any number of raters; on the 0-to-1 quality score it can treat the score as interval (0.62 versus 0.63 is a small disagreement) or nominal (any difference is total disagreement). `analysis/annotator_agreement.py` prints every number here.

**The three annotators agree moderately on routing and barely on quality.** On the 130 dossiers all three labelled, pairwise kappa on deserved attention is 0.44, 0.43 and 0.47, with bootstrap 95% intervals from about 0.23 to 0.63, and PABAK is 0.59, 0.59 and 0.57. Raw agreement is 79%. On the quality score, Spearman between pairs is 0.43, 0.31 and 0.45, and Krippendorff's alpha is 0.186 treated as interval and −0.04 treated as nominal, which is no agreement at all. The nominal figure is the honest one for anybody who reads the score as a grade; the interval figure says the annotators disagree by small distances.

**Each annotator is consistent about something different, which the README warned of.** Annotator 1 reads for wasted attention: 62% of their failure flags are that category. Annotator 2 reads for policy and evidence: 19% of their flags are evidence integrity and 19% policy, two to three times the others, which makes them the reader closest to the specification. Annotator 3 is generous and reads for calibration: their minimum quality score is 0.88, their median 0.96, and 29% of their flags say the agent's confidence or severity was miscalibrated. Their quality scores share one slope on severity and differ in intercept (0.84, 0.92 and 0.99), which is why Methodology borrows only the slope.

**The labels have three blind spots.** First, annotators never see the unrouted half of the corpus as a routing question. Only 6 of 606 flags say a signal was missed, and the evaluator's F1 against the majority vote on dossiers that never reached a human is 0.00, because the annotators almost never say yes there. Second, the wasted-attention flag and the wasted-escalation outcome field disagree: the flag covers 64% of the outcome-wasted dossiers, but only 26% of flagged dossiers are outcome-wasted, partly because annotators flag unrouted signals the field cannot see. Third, the free-text assessment is a fixed pool of phrases reused across dossiers, and on sig_0153 it contradicts the dossier's own disposition.

**I used the annotators as a check, never as a training label.** The majority vote is the reference for agreement statistics, the pre-registered split from Methodology stops any candidate being tuned on the held-out half, and every agreement number is reported per annotator and per slice. Where the evaluator lands is below the human band: kappa 0.12, 0.32 and 0.23 against the three annotators, with the first interval crossing zero, and PABAK 0.40, 0.47 and 0.40. Severity explains the gap. The annotators say yes to 43% of P1 signals and 6% of P2, so they track the agent's severity label, and the specification ignores that label. Adding the evaluator to the panel raises quality alpha from 0.186 to 0.295, but that figure is in-sample, because the slope comes from these annotators; it shows consistency with them and nothing more.

## Findings

**The evaluator agrees with the annotators less than they agree with each other, and the shortfall is concentrated in one severity band.** Table 1 puts the evaluator beside the human-versus-human numbers. On quality the evaluator sits inside the human band on every statistic. On deserved attention it sits below it, and the per-slice view says where: F1 against the majority is 0.51 on P1 dossiers and 0.00 on P2, P3, suppressed and never-routed dossiers. Two trivial baselines beat the evaluator's majority F1 of 0.38: calling every P0 or P1 signal deserving scores 0.57, and calling every non-benign hypothesis deserving scores 0.57. Both were rejected because the first breaks 4 of the 18 hand-derived specification verdicts and the second is the agent grading itself. The evaluator is the only definition that clears both the annotators and the specification.

**The agent's failure is selection, not volume.** 621 of 629 dossiers break at least one rule and 306 break a critical one. Table 2 lists the ten most frequent. Against the three deserved conditions, the agent's 294 routed signals have precision 31% and recall 56%. Against the two quoted obligations alone, 15% and 42%. The 72 deserving signals it never routed were 60 suppressions and 12 expiries, and 61 of them carried a written trigger or a timeout. Capacity never bound: candidates exceeded the 5-per-week cap in 23 of 245 owner-weeks and the agent itself exceeded it in 2, and routing every eligible signal (568) would have produced a churn rate among routed of 29% against a corpus base of 28%.

**One containment rule precedes most complaints, and no rule explains waste.** Complaints can only follow a routed customer-visible play, and there are 208 such dossiers with 16 complaints. Among them, dossiers that broke §8.2 (a customer-visible play on a legal-hold or M&A-quiet-period account) complained at 32% (10 of 31) against 3% (6 of 177), as Figure 3 shows. No other rule moved the complaint rate on that denominator. Two failures of similar frequency carried costs an order of magnitude apart: §8.2 fired on 41 dossiers and 10 drew a complaint, while §8.6, the wrong channel, fired on 21 and 1 did. Wasted escalations can only occur among the 294 routed signals, and owners marked 39% of those wasted. No rule separated them: off-hours paging 44% against 38%, routing below the floor 41% against 38%. A first draft found these rules doubling waste; that was a denominator error, routed against unrouted, and the same selection effect sits under every outcome field. What did separate wasted signals was the deserved verdict: owners marked 25% of routed deserved signals wasted (23 of 91) against 45% of routed signals that met no condition (92 of 203).

![Figure 3. The 16 complaints, one square each. Red: the play broke §8.2.](figures/complaints.png)

**The risk score ranks complaints and fails to rank waste, and the population matters.** The area under the ROC curve (AUC) is the probability that a randomly chosen harmful dossier scores above a randomly chosen harmless one; 0.5 is chance. On all 629 dossiers the risk score's AUC is 0.68 against wasted escalations and 0.80 against complaints. Four of its ten conditions fire only on routed dossiers, so those figures partly measure routing. On the populations where the harms occur, the AUC is 0.52 against wasted escalations among the 294 routed and 0.68 against complaints among the 208 routed customer-visible, almost entirely from the §8.2 condition. Against churn it is 0.52. The complaint figure is unstable: on the pre-registered split it is 0.89 on the development half and 0.61 on the held-out half, because only 16 events exist.

**Ungrounded numbers mark exaggerated real declines, and the most frequent rule is harmless.** Among routed signals the wasted rate was 40% with an M6 finding and 39% without, so the specification's warning that ungrounded numbers are "the most common way this system wastes attention" does not hold here. What M6 marks depends on what the corrected data shows (Figure 4). Where a real decline existed and the agent overstated it (121 dossiers), the routed accounts churned or downgraded at 53% (n = 47). Where the pipeline manufactured the decline (58), 12% (n = 17). Q2, the hypothesis-fit rule, fires on 80% of dossiers and separates nothing. Within each detector, churn and wasted rates match with or without it. Among unrouted signals churn is 26% either way. Annotators flag a wrong hypothesis on 19% of Q2 dossiers against 22% of the rest. A hand check of 20 random Q2 findings found 17 correct, 2 false alarms and 1 unclear. The rule is right about the dossiers and the dossiers do not matter.

The policy routes 105 fewer signals, and the ones it keeps churn more often and waste less. The cost is coverage: 16 accounts that churned or downgraded get no policy route, $3.02M of realised loss. The agent had reached 14 of those 16 and lost them anyway. Attribution is uncertain on 17 of the 26 signals involved and absent on the other 9, and 17 had a concurrent owner intervention, so the $3.02M is what the policy would not have seen, not what it would have lost. The agent's own severity ordering ranks as well as mine at equal volume (40% against 39% churn) but drops 45% of the specification's obligations.

## Limitations

1. **The least validated component supports the most frequent finding.** Q2's text test uses the default 0.35 threshold on topic labels with 1 to 5 fixtures each, and 10 of the 12 label thresholds never moved off the prior because the fixtures were too few. The 20-sample hand check gives a precision near 0.9 with a 95% interval of about 0.7 to 0.97. Both misses were near-verbatim statements of the hypothesis that the scorer put below threshold.
2. **Two scores depend on what they judge.** The quality score derives from the violations and can never serve as evidence about one. The deserved verdict reads the agent's own severity for 57 of its 163 positives. The quality slope comes from the annotators later used to report alpha, so that alpha is in-sample.
3. **The risk score is uncalibrated and partly selected on held-out data.** Its complaint AUC rests on 16 events and swings from 0.89 to 0.61 across the split. Its noisy-OR assumes independent conditions, and 111 dossiers fire two or more. Its condition set was chosen partly by held-out performance, which is model selection even though the magnitudes were never fitted.
4. **The held-out split is spent.** It held 10 positives, I read it four times, and further tuning needs fresh labels.
5. **The text layer is a list of conventions.** The quote splitter and the signature tagger recognise the email conventions this corpus uses and read anything else as current text. Blocks over about 512 tokens are scored truncated. The model reads English hypotheses only, though it scored the four other languages in the fixtures correctly. New dossiers outside this corpus need the model, a 700 MB download.
6. **The outcome data limits every comparison.** Complaint and wasted fields exist only for routed signals. The outcomes file gives contradictory renewal outcomes to 92 of 176 accounts, so loss is counted once per account at its worst outcome. Attribution is uncertain wherever anything happened. No comparison here is causal.
7. **The evaluator sees only dossiers that exist, and some bad dossiers break no rule.** 230 real API-call drops, 352 real seat drops and 48 written triggers never became a dossier. sig_0385 was a wasted escalation with zero violations and a quality score of 1.00.
8. **One deployment, synthetic data.** No claim here extends beyond this corpus.

## If you had 3 months

1. **Instrument the detection stage.** Log every detector firing, not only the ones that became dossiers, so first-stage recall becomes a measured number and the 48 missed triggers become a dashboard series. Every downstream recall figure is bounded by this one.
2. **Make attribution a design instead of a field.** Randomise routing on the margin, in the tier-3 band only and never on a specification obligation, and run any new policy in shadow beside the agent before a queue changes. Log owner actions at decision time. Without this, no comparison between policies is causal, and the $3.02M above stays a bound rather than a cost.
3. **Treat labels as a versioned instrument.** Adjudicated annotation of about 30 dossiers a week against a written rubric, with kappa, PABAK and the intraclass correlation reported per batch, and rubric changes handled as migrations that re-grade what was graded. Retire a held-out set once it has been read.
4. **Run the rules as continuous integration.** Every specification rule is already a test; run the 29 on each agent change and alert on drift in per-rule rates. The containment rules (§8.2, §8.3, §8.4, §8.7) gate deploys, because those are the ones with a measured cost.
5. **Calibrate the risk score and state the operating point.** Fit an isotonic calibration on rolling outcomes, report Brier score beside AUC, evaluate each harm only on the population where it can occur, and publish precision at each owner's capacity rather than a corpus-wide number.
6. **Close the loop per violation class.** Each class gets an owner and a fix; the appended-email fabrication in 17 dossiers is one prompt change. Re-run the corpus after each fix and ship the tiered ranking behind the per-owner budget, measuring wasted rate and complaint rate on the overlap set.
7. **Price the slot.** Until Cartogram states what a CSM slot is worth against a missed churn, precision and coverage can be measured but never traded. Everything above makes the measurement honest. Only that number makes the decision.
